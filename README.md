# فواتيري — تطبيق الفواتير والمحاسبة الذكي 🧾📱
### Smart Invoicing & Accounting Android App for Retail and Merchants

تطبيق أندرويد متكامل ومصمم خصيصاً للمحلات والأنشطة التجارية وإدارة الفواتير والعملاء والمبيعات اليومية، يدعم الطباعة على الطابعات الحرارية عبر البلوتوث (ESC/POS 58mm / 80mm)، وتصدير كشوفات الحساب بصيغة PDF، مع محرك إدخال صوتي ذكي باللغة العربية، وإدارة كاملة للعملاء وحركات الصندوق والديون والمخزون.

---

## 🌟 الميزات الرئيسية (Key Features)

### 1. إدارة الفواتير والمبيعات السريعة
- إنشاء فواتير حرارية احترافية بواجهة تفاعلية تشبه الفاتورة الورقية الحقيقية (شكل الفاتورة الحرارية الكلاسيكي).
- إدخال الأصناف، الكميات، الأسعار، والإجمالي مع احتساب فوري تلقائي وخصم مخصص.
- دعم البيع **نقداً** أو **أجل** (على الحساب) مع تسجيل المبلغ الواصل والمتبقي بدقة.
- إمكانية حذف أو إلغاء أي صنف من الفاتورة فوراً عبر الواجهة أو عبر الأوامر الصوتية.
- زر تثبيت سفلي (Sticky Action Bar) للحفظ السريع والطباعة الفورية.

### 2. محرك إدخال صوتي ذكي متقدم (Arabic Voice Engine)
- إدخال الأصناف بالأوامر الصوتية الطبيعية بالعامية والفصحى (مثال: *"4000 كرتون عصير 2"* أو *"1000 تونة 2"*).
- دعم الأوامر الصوتية لإلغاء أو حذف الأصناف (مثال: *"احذف عصير"* أو *"إلغاء الصنف الأول"*).
- دعم أمر مسح وتفريغ الفاتورة صوتياً (*"مسح الفاتورة"* أو *"مسح الكل"*).
- ميزة التراجع الصوتي الفوري (Undo) بنقرة واحدة.

### 3. إدارة حسابات العملاء وسندات القبض (CRM & Ledger)
- قائمة تفصيلية بالعملاء مع عرض الرصيد الصافي المتبقي لكل عميل (صافي المديونية / المسدد).
- كشف حساب تفصيلي للعميل يعرض كل الفواتير وسندات القبض مرتبة زمنياً.
- إمكانية إضافة سندات قبض (دفعات نقدية) وتسديد جزئي أو كلي لحساب العميل.
- تصدير ومشاركة كشف حساب العميل بصيغة **PDF** رسمي جاهز للمشاركة عبر واتساب أو الطباعة.

### 4. إدارة المخزون وتنبيهات النواقص (Inventory Management)
- متابعة الكميات المتاحة في المخزون لكل صنف (`stockQuantity`).
- خصم تلقائي للكميات من المخزون عند إتمام كل فاتورة بيع.
- تنبيهات مرئية للأصناف التي اقتربت من النفاد (`minStockAlert`).

### 5. التقارير المالية ورسم بياني تفاعلي (Financial Reports & Charts)
- تقرير الأرباح والخسائر والمبيعات اليومية والأسبوعية والشهرية.
- رسم بياني بياني تفاعلي للمبيعات الشهرية تم إنشاؤه عبر **Jetpack Compose Canvas** بدون أي مكتبات خارجية ثقيلة.
- إحصائيات سريعة في لوحة التحكم (مبيعات اليوم، الواصل اليوم، عدد الفواتير).

### 6. دعم الطباعة الحرارية المتطورة (ESC/POS Thermal Printing)
- اتصال سلس عبر البلوتوث مع طابعات الإيصالات 58 مم و 80 مم (Xprinter, Goojprt, Epson, وغيرها).
- محرك معالجة للنصوص العربية وتحويلها إلى رسومات نقطية عالية التباين (Bitmap ESC/POS) لضمان طباعة عربية واضحة ومثالية على كافة الطابعات حتى التي لا تدعم الجداول العربية محلياً.

### 7. النسخ الاحتياطي والأمان (Backup & Data Protection)
- تشفير قاعدة البيانات وحفظ البيانات محلياً على الجهاز (Offline-First).
- تصدير نسخ احتياطية واستعادتها بسلامة كاملة وتأكيد عدم فقدان البيانات.
- إيقاف النسخ الاحتياطي غير الآمن عبر `android:allowBackup="false"` في ملف المانيفست.

## 🛠️ المكدس التقني (Tech Stack)

| التقنية | الاستخدام |
| :--- | :--- |
| **Kotlin 100%** | اللغة الأساسية لكتابة كامل شفرة المشروع |
| **Jetpack Compose + Material 3** | بناء واجهات المستخدم بنمط حديث وعصري داعم لـ RTL |
| **MVVM + Clean Architecture** | نمط المعمارية، فصل البيانات عن المنطق وعن الواجهات |
| **Kotlin Coroutines + StateFlow** | إدارة العمليات غير المتزامنة وتدفق البيانات الفوري |
| **Room Database (SQLite)** | قاعدة البيانات المحلية مع فهارس محسنة ومعاملات `@Transaction` |
| **ESC/POS Bluetooth & Canvas Engine** | معالجة وطباعة الفواتير على الطابعات الحرارية |
| **Android Keystore & Clean Security** | حماية البيانات وتأمين المعلومات المالية الحساسة |

## 🏗️ خطوات البناء والتشغيل (Build & Run)

### المتطلبات:
- Android Studio Ladybug / Meerkat أو أحدث
- JDK 17 أو 21
- Android SDK 36 (الحد الأدنى المدعوم Android 7.0 - API 24)

### الأوامر البرمجية:
```bash
# بناء التطبيق (Debug APK)
gradle assembleDebug

# تشغيل جميع الاختبارات الآلية (Unit & Robolectric Tests)
gradle :app:testDebugUnitTest

# تثبيت التطبيق على جهاز متصل
gradle installDebug
```

## 📂 هيكلة الحزم (Project Structure)

```text
app/src/main/java/com/example/
├── data/
│   ├── local/          # كيانات Room (Entities)، الواجهات (DAOs)، قاعدة البيانات (AppDatabase)

│   └── backup/         # إدارة النسخ الاحتياطي والاستعادة (BackupManager)

│   ├── model/          # نماذج الدومين المحاسبية والمالية
│   └── einvoicing/     # واجهة الاستعداد للفاتورة الإلكترونية والـ QR
├── ui/
│   ├── components/     # المعاينة التفاعلية للفاتورة، تقارير PDF، ورسم Canvas البياني
│   ├── screens/        # الشاشات: الرئيسية، الفاتورة، العملاء، السجل، التقارير، الإعدادات، الطابعة
│   ├── theme/          # الألوان الطبيعية، الرموز، DesignTokens، وأنماط M3

│   └── viewmodels/     # نموذج العرض الموحد (InvoiceViewModel)
└── printer/            # مدير اتصالات البلوتوث ومحول ESC/POS
```

## 🔒 الأمان وحماية البيانات (Security & Privacy)

- **Offline-First:** يعمل التطبيق بشكل كامل دون الحاجة لأي اتصال بالإنترنت، مما يحافظ على خصوصية فواتير المحل وحسابات العملاء.
- **منع السجلات الحساسة:** لا يتم تسجيل أي مبالغ أو أرقام هواتف أو بيانات شخصية في سجلات النظام (Logcat).
- **قواعد الحماية:** تفعيل `android:allowBackup="false"` لمنع سحب قاعدة البيانات عبر أدوات الاستخراج غير المصرح بها.
