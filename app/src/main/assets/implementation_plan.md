# خطة عمل: إيقاف اختفاء واختصار البيانات عند زيادة طول النصوص والأصناف في الفواتير

## المشكلة المحددة:
عندما تصبح أصناف الفاتورة أو النصوص والتفاصيل أطول قليلاً، أو عند زيادة عدد الأسطر، تختفي بعض البيانات أو تحدث اقتطاعات (Clipping / Overflow) في:
1. **شاشة الفاتورة التفاعلية (`NewInvoiceScreen`):** القائمة العمودية للأسطر والجدول المصغر.
2. **معاينة إيصال الفاتورة (`InteractiveReceiptView`):** ارتفاع الخلايا الثابت (`height(30.dp)`) وتحديد سطر واحد (`singleLine = true`) للنصوص يمنع عرض النصوص الطويلة ويؤدي لاختفائها أو قصها.
3. **ملف الـ PDF (`InvoicePdfHelper`):** جداول الطباعة ومساحات الصفحات التي قد تتقاطع أو تقطع النصوص.
4. **طباعة الإيصال الحراري عبر البلوتوث (`ThermalImageConverter`):** صور الطباعة التي تتطلب التفافاً صحيحاً للنصوص الطويلة.

---

## الخطوات والحلول الهندسية المقترحة:

### 1. إزالة الارتفاعات الثابتة والسماح بالنمو الديناميكي للخلايا:
- في `InteractiveReceiptView.kt`: استبدال `height(30.dp)` بالارتفاع المرن والتفاف النصوص (`softWrap = true`, `maxLines = 3`) لكي تتمدد الخلية رأسياً عندما يكون الوصف أو اسم الصنف طويلاً بدلاً من اختفائه.
- التأكد من استخدام وزن مرن (`Modifier.weight(...)`) وخلايا تدعم الالتفاف التلقائي.

### 2. تمكين التمرير العمودي الكامل للفاتورة (`NewInvoiceScreen`):
- مراجعة الحاويات في `NewInvoiceScreen.kt` وجعل القائمة والجدول قابلة للتمرير بسلاسة (`verticalScroll` أو `LazyColumn` متكاملة مع باقي عناصر الفاتورة) بحيث لا تختفي الأسطر السفلية عند إضافتها أو زيادة طولها.

### 3. دعم التفاف النصوص وتحجيم الخط في تصدير الـ PDF والطباعة (`InvoicePdfHelper`):
- تحديث رسم خلايا الجدول في `InvoicePdfHelper.kt` لتدعم تعدد الأسطر (Multi-line text wrapping) عند زيادة طول وصف الصنف، لمنع اقتطاعه أو اختفائه في المستند المصدر.

### 4. التحقق والاختبار الشامل:
- تشغيل أداة `compile_applet` للتأكد من سلامة البناء وعدم وجود أخطاء في الـ Kotlin.
