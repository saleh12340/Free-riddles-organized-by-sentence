# خطة تطوير نظام إدارة العملاء والعمليات المالية

هذه الخطة توضح خطوات جعل شاشة العملاء هي الشاشة الرئيسية للتطبيق، مع تمكين عرض تفاصيل حسابات العملاء وعملياتهم، وإضافة وتعديل الفواتير والسندات (قبض وصرف) والقيود اليومية.

---

## 1. الأهداف الرئيسية
1. **جعل شاشة العملاء الشاشة الرئيسية**: عند فتح التطبيق، يظهر المستخدم قائمة العملاء مباشرة مع بطاقات تفصيلية توضح رصيد كل عميل (له/عليها).
2. **شاشة حساب وعمليات العميل (Customer Account Statement)**:
   - عرض رصيد العميل الحالي (إجمالي المبيعات، إجمالي المدفوعات، الرصيد المتبقي).
   - عرض سجل العمليات كاملاً (فواتير، سندات قبض، سندات صرف، قيود يومية).
   - إمكانية تعديل أو حذف أو طباعة أي عملية أو فاتورة.
3. **إضافة وتعديل الفواتير والسندات والقيود**:
   - **الفواتير**: إنشاء فاتورة جديدة أو تعديل فاتورة سابقة (مع الإدخال اليدوي والصوتي وحساب الإجمالي والمتبقي).
   - **سندات القبض والدفع (صرف)**: تسجيل دفعة نقدية من أو إلى العميل مع تحديث رصيده لحظياً.
   - **القيود اليومية والتسويات**: إضافة قيود محاسبية أو تسويات للعميل عند الحاجة.

---

## 2. الخطوات البرمجية والتنفيذية

### 2.1 تحديث نموذج البيانات وقاعدة البيانات (Room Entities & DAOs)
- التأكد من دعم الجداول لعمليات العملاء، الفواتير، السندات (قبض/صرف)، والقيود.
- تحديث `CustomerEntity` و `InvoiceEntity` و `TransactionEntity` (للسندات والقيود) لتخزين وحساب الأرصدة بدقة.

### 2.2 تعديل شاشة العملاء الرئيسية (`CustomersScreen.kt` كشاشة رئيسية)
- جعل `CustomersScreen` هي الواجهة الافتتاحية للتطبيق.
- تصميم بطاقات تفصيلية لكل عميل تعرض:
  - اسم العميل، رقم الهاتف، العنوان.
  - رصيد الحساب الحالي مع تلوين واضح (مدين / دائن).
  - أزرار سريعة: عرض كشف الحساب، إضافة فاتورة جديدة، إضافة سند قبض/صرف.
- زر عائم (FAB) لإضافة عميل جديد.

### 2.3 تطوير شاشة تفاصيل وكشف حساب العميل (`CustomerAccountStatementScreen.kt`)
- ترويسة الحساب (إجمالي المبيعات، إجمالي المقبوضات، الرصيد الصافي).
- تبويبات أو قائمة مدمجة لعرض جميع حركات العميل (الفواتير، السندات، القيود).
- أزرار لإضافة معاملة جديدة للعميل (فاتورة جديدة، سند قبض، سند صرف، قيد تسوية).
- خيار تعديل أو حذف أي عملية مع تحديث أرصدة العميل فوراً.

### 2.4 تطوير شاشات إضافة وتعديل الفواتير والسندات
- **شاشة الفاتورة (`NewInvoiceScreen.kt`)**: دعم إنشاء/تعديل الفاتورة وربطها بالعميل المحدد.
- **شاشة سند القبض/الصرف (`TransactionDialogScreen.kt` أو حوار مخصص)**: إدخال المبلغ، نوع السند (قبض / صرف)، البيان، والتاريخ.
- **شاشة قيد التسوية**: إدخال قيد محاسبي للعميل.

---

## 3. خطة التحقق والاختبار
- تجميع التطبيق (`compile_applet`) للتأكد من خلوه من أخطاء بناء Kotlin.
- فحص تدفق العمليات من الشاشة الرئيسية للعملاء إلى كشف الحساب وإضافة/تعديل الفواتير والسندات.
